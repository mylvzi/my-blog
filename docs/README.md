## 使用与维护

本仓库采用与参考站 [`TsingJyujing/blogs`](https://github.com/TsingJyujing/blogs) 相同的 GitBook 内容结构：`docs/README.md` 是首页，`docs/SUMMARY.md` 控制左侧目录，每个栏目使用自己的 `README.md` 作为入口页。

将仓库连接到 GitBook 的 Git Sync 后，GitBook Cloud 会负责同款的文档站界面、搜索、左侧目录、页内目录和移动端体验。新增页面后，请将其补充到 `docs/SUMMARY.md`；也可以运行 `python3 docs/gen_summary.py` 自动重建目录。
